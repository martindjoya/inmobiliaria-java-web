# Sistema Web para Inmobiliaria

Aplicación web para la administración de una inmobiliaria, desarrollada con Java EE, JSP, JDBC, Bootstrap y una base de datos relacional.

## Objetivo

Gestionar usuarios, roles, propiedades, citas, solicitudes, documentos y reportes mediante una aplicación web con arquitectura MVC y control de acceso.

## Metodología

El proyecto se desarrollará mediante Scrum en tres sprints de siete días:

1. Sprint 1: base de datos, estructura, landing page y autenticación.
2. Sprint 2: perfiles, propiedades, imágenes, características y buscador.
3. Sprint 3: citas, solicitudes, favoritos, reportes, pruebas y documentación.
