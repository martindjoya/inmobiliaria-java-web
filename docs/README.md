Dream House S.A.
================

Aplicación web para la gestión de una inmobiliaria.

Tecnologías
- Java / JSP
- JDBC
- MySQL/MariaDB
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Apache Tomcat

Estructura
- database/   → Base de datos
- src/        → Código Java
- WEB-INF/    → Clases y librerías
- WebContent/ → Recursos web
- css/        → Hojas de estilo
- docs/       → Documentación del proyecto
